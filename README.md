# Task Manager API

A REST API for managing tasks, built with Django and Django REST Framework.

## Features
- Create, read, update, and delete tasks

## API documentation

- Swagger UI: `/api/docs/`
- OpenAPI schema: `/api/schema/`
- Protected endpoints use HTTP Basic authentication. In Swagger, click
  **Authorize** and enter your username and password.

Install the dependencies with `pip install -r requirements.txt`, then start the
development server with `python manage.py runserver` to open the Swagger UI.
